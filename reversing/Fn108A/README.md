## Revision contra el EXE (desensamblado, `dumpbin /disasm` del EXE canonico)
- **CMBlur::MotionBlurRender 0x71D700** (`ret`, cdecl, 7 argumentos que el llamador limpia): no hace nada. **MotionBlurOpen 0x71D710 / MotionBlurClose 0x71D720** (`mov eax,1; ret`): devuelven true (el C++ deja `AL = 1`; el llamador del EXE no lee el resto de EAX).
- **CMBlur::SetDrunkBlur 0x71D730** (cdecl, un float): `fld arg; fcomp 1.0; test ah,5; jnp` -> si el argumento NO es menor que 1 (**NaN incluido**) escribe `Drunkness` (0xC73C58) = 1.0; si no, `fcomp 0.0; test ah,41h; je` -> si es mayor que cero lo guarda tal cual; si no (<= 0, **-0.0 incluido**) escribe +0.0. **Hallazgo de la lectura del desensamblado (los fixtures lo cubren con NaN y ceros con signo)**: el C++ anterior era `std::clamp(d, 0, 1)`, que deja pasar NaN (el EXE escribe 1.0) y -0.0 (el EXE escribe +0.0). Se reescribio con las tres ramas del EXE.
- **CMBlur::ClearDrunkBlur 0x71D780**: `CTimer::ms_fTimeScale` (0xB7CB64) = 1.0 y `Drunkness` = 0.
- **CRubbish::SetVisibility 0x7204C0** (`ret`; los llamadores empujan un dword y lo limpian, el primero con `and ecx,0FFFFFF01h`), **CHeli::SpecialHeliPreRender 0x6C4750** (`ret`, sin argumentos) y **CPlaneBanners::Init 0x717820** (`ret`): vacias.
- **CTaskSimpleInAir::ApplyRollAndPitch 0x678E80** (thiscall, `ret 4`): vacia; el llamador del EXE es `CPed::PreRender` (0x5E6611).
- **CTaskSimpleGoToPointFine::SetMoveRatio 0x65F3A0** (thiscall, `ret 4`): `[this+0x20]` = el dword del argumento (bits tal cual, sin pasar por float).
- **CVehicleModelInfo::GetWheelSize 0x6A06F0** (thiscall, `ret 4`, devuelve float en ST0): el byte bajo del argumento (`mov al,[esp+4]; test al,al`) elige `[this+0x40]` (delantera) o `[this+0x44]` (trasera); el resto de los bytes del argumento no cuentan.
