## Oraculo independiente
`fixture_oracle.py` reimplementa solo lo observable desde el desensamblado (memoria escrita, eventos, valores devueltos, constantes). Para `fsin` / `fcos` **no reimplementa el microcodigo de la FPU** (el resultado de la x87 para argumentos cercanos a multiplos de pi depende de su reduccion interna de 66 bits): comprueba que solo ST0 sea valido, los casos especiales exactos (NaN: el mismo NaN silenciado; infinito: indefinido real; |x| >= 2^63: el operando sin cambios, C2 = 1) y, para el resto, que ST0 este a distancia <= 2^-62·|sin x| + 2^-65·|x| del seno exacto calculado con aritmetica decimal de 140 digitos y pi de 100 digitos; la igualdad bit a bit con el EXE la da la comparacion par a par. Para `GetTimeStep` el oraculo es exacto (float cargado con `fld`: denormales normalizados, NaN senalizante silenciado).
