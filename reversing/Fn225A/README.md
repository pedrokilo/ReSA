## Correccion que dio el banco (fuente de produccion)
**`D3D9RasterFormat::VideoMemoryRasterListRestore` (0x4CC970), tipo 5 (textura de camara), reintento con el formato del back buffer**: el EXE (0x4CCACB y 0x4CCAE1) calcula el uso de `CreateTexture`/`CreateCubeTexture` del reintento como `(nibble bajo de +0x0A != 0) ? 0x400 : 0`, SIN el `or edx,1` (D3DUSAGE_RENDERTARGET) que si lleva el primer intento (0x4CCA69). La reconstruccion ponia siempre el bit 1. Ahora `CreateCameraTextureObject` recibe un parametro `renderTarget` (1 en el primer intento, 0 en el reintento). La primera corrida corta (64 casos por funcion) ya lo detecto: 3 de 64 casos de esa funcion difirieron en el campo de uso de la segunda llamada; las otras siete funciones pasaron.
