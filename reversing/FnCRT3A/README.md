## Notas de diseño de `pow`

- Los `movlpd`/`movsd` entre registros conservan la mitad alta; los `*sd` no tocan la alta; los packed (`mulpd`, `addpd`, `pshufd 0xEE`) sí la usan. Se transcribieron todos con el mismo intrínseco para que el comportamiento no dependa de que la mitad alta «no importe».
- Las constantes se cargan como `__m128d` (nunca como `double` devuelto por valor): un `double` devuelto pasa por ST0 y silencia NaN señalizantes (0x88BDE8 es uno).
- Dos `divsd`/`mulsd` solo levantan banderas (división por cero e inválido) y su resultado no se usa; se conservan con una escritura `volatile` para que el compilador no los elimine. El banco compara las banderas MXCSR: 0 diferencias.
- Los datos que el EXE deja en ST0 (resultado) se devuelven como `double` normal de cdecl; el manejador 0x82872C recibe (&x, &y, &resultado, código) con x e y consecutivos, como en el EXE.
