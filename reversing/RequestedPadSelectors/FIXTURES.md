# CPad selectors — prepared, not compiled or executed

Scope contains 61 exact catalogue entries: 52 in the pure bank and 9 requiring actor context. No validation flags were changed. This bank does not test controller acquisition, initialization, real OS input, vibration, or frame updates.

The pure bank contains 3,876 fixtures per function, 201,552 comparisons total. It covers all four valid modes, button pressure 0–255, 20 individual button/state fields with idle/press/held/release transitions, both melee arguments, every DisablePlayerControls bit individually, seven individual disable flags and bApplyBrakes. Steering indexes stay within 0–9. Eighteen ordinary analog boundaries cover ±128, ±35 deadzone and ±15/±5 hysteresis; eight additional signed-short extremes are explicitly ABI stress rather than ordinary controller input. The Cartesian analog/history cases test each stateful static direction independently. Timer fixtures cover unsigned subtraction across wraparound.

Original and candidate receive separate copies of the same private CPad. The fixture uses the existing object's trivial copy then clears that copy: no CPad constructor, Clear(), keyboard, mouse, or system input is invoked. Field seed writes use byte copies, not indexing beyond individual scalar members. The return contract compares int16 low 16 bits, uint8 low eight bits, uint32 all 32 bits, and canonical declared bool values from AL; undefined upper EAX bits are not evidence of a mismatch.

The bank saves and restores both global Pads objects, the complete range containing four analogue histories, and the original clock. Each leg resets these globals to identical values and compares their complete bytes afterwards. GetSteeringLeftRight's private buffer write is compared as part of the entire CPad object. All other pads/global fields are included, so unexpected mutation is visible. State is restored before the outer harness verifies all hook entries, both candidate/GTA bytes, all virtual tables and every enabled/locked flag. The target switch uses ExactSwitch for each leg. Only NOTSA_WinMain remains active while its harness executes; it returns before RW, input and graphics setup. This is not accreditation of game startup or normal play.

`scope.json` binds all 61 identities to current source hashes and fresh REA evidence IDs. There are 59 successful dossiers with full inclusive body ranges, assembly and pseudocode; both GroupControl*JustDown lookups failed. Their primary PE byte files are explicitly bounded catalogue windows, not invented Ghidra bodies. Every successful dossier also has exact bytes independently extracted from the canonical EXE. The CPad source snapshots accompany the combined evidence.

Nine actor functions are deferred from the compiled dispatch: GetPedWalkLeftRight-ped, GetPedWalkUpDown-ped, AimWeaponLeftRight, AimWeaponUpDown, LookAroundLeftRight, LookAroundUpDown, GetDisplayVitalStats, WeaponJustDown and GetWeapon. Walk/look can use nullptr and a private CPed attached-pointer fixture. Aim additionally needs private vehicle driver/passenger states. The three gun-context selectors need CTaskUseGun/GetSimplestActiveTask collaborators at 0x600F70/0x6819D0 and task virtual GetTaskType slot 0x10; original GetWeapon queries these before its mode switch, while current source queries only modes 0/1. A future context bank must record and preserve this observable call order, distinguish task-null/gun/gang-driveby/other and attachment branches, and cannot claim collaborator validation. No FindPlayer, engine, pool or RW context may be substituted implicitly.

Builder and runner are prepared only. Python syntax was checked; no C++ compilation, GTA execution, registration or approval has occurred.

Full original body review found only two direct calls in the 50 successful pure dossiers: CarGunJustDown calls 0x53EDC0 and MeleeAttackJustDown calls 0x53EF40. Primary PE listings prove each helper compares only two private controller fields and returns; their respective complete reachable bodies end at 0x53EDD6 and 0x53EF56. They use no engine/global/OS services and are left real, not stubbed or counted as validated identities. CarGunJustDown mode 3's helper reads LeftShoulder1 whereas current source uses RightShoulder1; this is a static candidate mismatch for the one-hot fixtures to reproduce, not an applied fix or failure classification.
